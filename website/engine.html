Technical Dossier v2.0

Under the Hood.

The architecture behind autonomous, unscripted civilization. This is not a game engine. It is a behavioral simulation kernel.

Pillar 01

The Mind of an Agent

Every decision passes through a four-stage pipeline. There is no if-statement. There is a weighted cascade from reflex to deliberation.

Stage 1

Reflex

The fastest path. If an agent's hunger exceeds a critical threshold, or a predator is within striking distance, the reflex layer fires before any cognitive process. This is not a script — it is a weighted urgency signal that gates higher-level processing.

threshold.hunger.critical 0.85
threshold.threat.proximity 3.0 units
Stage 2

Value Alignment

The agent's personality profile (Big Five) and attachment style filter the available action set. A high-neuroticism agent weights safety over exploration. A high-agreeableness agent weights social harmony over personal gain. Values are not labels — they are mathematical weights in the utility function.

filter.openness.weight ×1.2
filter.conscientiousness.weight ×0.9
Stage 3

Habit

Repeated actions form procedural memory. If an agent has successfully performed an action sequence 20+ times, it enters a "habit buffer" and executes without full deliberation. This frees working memory for novel situations. Habits can be broken when they stop producing results.

habit.threshold 20 repetitions
habit.decay.rate 0.04 / tick
Stage 4

Cognitive Deliberation

For novel or high-stakes decisions, the GOAP planner runs an A* search over the agent's known action rules. The planner projects possible futures and scores them against the agent's current drives. This is where invention happens — an agent discovers that combining two known actions produces a new capability.

planner.depth 5 steps
planner.branching.factor 3.2 avg

Pillar 02

Theory of Mind

Agents build mental models of other agents — and they get it wrong. A misattributed intention can spark a blood feud. An accurate read can forge an alliance that lasts generations.

Signal

Observing Behavior

Agents infer intent from observed actions. When Agent A shares food with Agent B, Agent B updates its model: "A has a high agreeableness score and low neuroticism." This inference may be accurate — or it may be projection based on B's own personality.

Noise

The Misread

An agent with high neuroticism interprets neutral actions as hostile. An agent with low openness fails to recognize cooperative signals. These misreadings are not bugs — they are the engine of tragic narratives. Tribal feuds, holy wars, and betrayals all originate here.

attribution.error.rate 0.17

Pillar 03

Realism Reports

Every simulation run is validated against real-world anthropological and criminological data. The engine does not just generate plausible histories — it generates statistically valid ones.

Validation Metric

Homicide Share

Cross-cultural homicide rates fall within 0.5–4.0 per 100,000 for stable populations. ASHB2 runs consistently produce 1.2–3.8, aligning with ethnographic baselines. Spikes occur only during resource collapse — which matches real-world data.

baseline.rate 1.8 / 100k
famine.spike 4.2 / 100k
Validation Metric

Demographic Sustainability

Populations stabilize between 30–120 agents depending on carrying capacity. Extinction events occur in ~22% of runs, consistent with real-world hunter-gatherer extinction rates for small founding populations.

stability.rate 78%
extinction.rate 22%
Validation Metric

Cultural Stability

Belief systems persist for 80–400 ticks before splitting or dissolving. The mean cultural half-life is 185 ticks, which maps to ~3–5 generations in real-world small-scale societies before significant drift occurs.

half.life.mean 185 ticks
split.threshold 12 adherents
Validation Metric

Technological Progression

Invention rates follow a logarithmic curve: rapid early discoveries, then a plateau. This matches the observed pattern in real archaeological records, where tool complexity increases quickly in the first 500 generations and then stabilizes.

inventions.by.tick.1000 8 avg
inventions.by.tick.5000 16 avg
